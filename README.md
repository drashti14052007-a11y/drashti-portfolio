# Drashti Patel — Portfolio

Food Processing Technology student portfolio focused on R&D decision-support work (NoteStack, HeatGuard, TrackBot).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Design system

Quiet Lab palette · Fraunces + Manrope · floating pill nav · ghost buttons · outlined cards.
